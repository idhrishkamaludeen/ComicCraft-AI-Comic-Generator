# ComicCraft – AI Comic Generator

ComicCraft is an AI-powered web application that transforms user ideas into engaging comic stories with visually generated comic panels and downloadable PDF output.

## 🚀 Features

- AI-powered story generation
- Automatic comic panel generation
- Anime, Manga, Comic and Cartoon visual styles
- Character and scene consistency across panels
- Real-time comic preview
- PDF comic export
- Responsive web interface
- Demo/reference image fallback for reliable presentation
- Modular Python backend architecture

## 🧠 How ComicCraft Works

```text
User Prompt
     ↓
Gemini AI Story Generation
     ↓
Panel-wise Story & Visual Descriptions
     ↓
AI Image Generation
     ↓
Comic Panel Images
     ↓
Web Preview
     ↓
Downloadable PDF
